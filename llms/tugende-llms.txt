# Tugende

> Tugende is a for-profit social enterprise founded in 2012 in Uganda that uses asset finance, technology, and a customer-centric model to help informal-sector entrepreneurs (MSMEs) own income-generating assets — motorcycles (boda bodas), taxis, matatus, boat engines, smartphones, and small-business equipment — through lease-to-own financing. Operating in Uganda and Kenya with 800+ staff, Tugende has served over 52,000 clients. Backed by Partech. Tugende publishes no public API or developer program as of 2026-07-21.
